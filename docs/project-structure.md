# Project Structure

This document describes the initial structure for Techet.

## Application code

- `src/app/` for application routes and page-level structure
- `src/components/` for reusable UI components
- `src/features/` for feature-specific logic and modules
- `src/lib/` for shared libraries and helpers
- `src/styles/` for global styles and design tokens
- `src/hooks/` for reusable hooks
- `src/types/` for shared TypeScript types
- `src/services/` for API and business services
- `src/utils/` for utility functions

## Documentation

- `docs/architecture.md` for system design notes
- `docs/roadmap.md` for development milestones
- `docs/security.md` for security expectations

## Testing

- `tests/unit/` for unit tests
- `tests/integration/` for integration tests
- `tests/e2e/` for end-to-end tests

## Repository templates

- `.github/pull_request_template.md` for pull request guidance
- `.github/issue_template.md` for issue guidance
